# 화면 용어 — 명사형 · 공식 표현

> 화면(메뉴 · 단추 · 열 이름 · 제목 · 안내문 · 오류 메시지)에 쓰는 말의 정본. 새 화면을 만들거나 문구를 고칠 때
> 여기 표를 따른다. 코드 주석은 해당 없다(주석은 설명이 우선).

## 규칙

1. **이름은 명사형.** 단추 · 메뉴 · 열 이름 · 대화상자 제목은 「~하기」 가 아니라 명사 — 「수정」 「삭제」 「재발송」 「홈 게시」.
2. **동작은 공식 동사.** 안내문에서 동작을 말할 때는 아래 표의 동사를 쓴다 — 「고치다 · 지우다 · 넣다 · 누르다 · 걸다」 같은 구어는 쓰지 않는다.
3. **부정은 「~하지 않습니다」.** 「안 삭제합니다」 가 아니라 「삭제하지 않습니다」.
4. **개념어는 하나로.** 같은 것을 두 이름으로 부르지 않는다(아래 「개념」).

## 개념

| 쓰는 말 | 뜻 | 다른 말로 부르지 않는다 |
| --- | --- | --- |
| 타입 | 객체의 종류 (`ObjectType`) | 종류 · 클래스 |
| 객체 | 타입의 인스턴스 | 항목 · 레코드 |
| 속성 · 속성 정의 | 타입이 담는 칸과 그 정의 | 필드 · 칸(안내문에서 「칸」 은 허용) |
| 속성 종류 | 속성이 담는 값의 종류 — 글 · 숫자 · 날짜 · 고를 값 … (`data_type`). 화면에서는 「종류」 로 줄여 적어도 되지만, **타입을 「종류」 라고 부르지는 않는다** | 데이터 타입 · 자료형 · 형식 |
| 종류 변경 | 속성 종류를 바꾸면서 저장된 값도 새 종류로 바꾸는 것 — 계획을 먼저 보고 적용한다 | 형변환 · 타입 변경 · 종류 바꾸기 |
| 변환 · 변환할 수 없는 값 | 저장값을 새 종류의 값으로 바꾸는 것과, 규칙으로는 바꿀 수 없는 저장값(「12 kg」 → 숫자) | 캐스팅 · 파싱 실패 · 오류값 |
| 대체 값 · 값 삭제 | 변환할 수 없는 값 대신 넣을 값과, 그 값을 비우는 것 — 값마다 사람이 정한다 | 매핑 · 치환값 · 널 처리 |
| 식별자 | 타입 안에서 유일한 코드 (`key`) | 키 · 코드 |
| 이름 | 사람이 읽는 표시명 (`label`) | 라벨 |
| 관계 · 관계 종류 | 객체 사이의 연결과 그 정의 | 링크 · 엣지 |
| 참조 속성 | 칸에 저장한 관계 (`object_ref`) | 참조 칸 |
| 축 · 기록 | 가리켜지는 타입(개발모델 · 과제 · 부서)과 그것을 가리키는 타입(시장 서비스 건 · 시험 결과). **둘 다 타입**이고, 타입마다 고르는 칸이 「축 · 기록」(`usage` = `axis` · `log`)이다. 저장은 같고 검색 · 상세 · 그래프의 기본 동작만 다르다(ADR 0011). 둘을 잇는 것은 참조 속성이다(ADR 0009) | 마스터 · 트랜잭션 · 표 · 쓰임(「쓰임」 은 사용 중이라는 뜻이다) |
| 가리키는 기록 | 축 하나를 참조 칸으로 가리키는 기록의 수 — 상세 · 그래프가 기록을 줄 대신 이 수로 보이고, 누르면 그 칸으로 걸러진 목록으로 간다 | 역참조 · 백링크 |
| 참조 후보 | 표의 열이 가리킬 법한 있는 타입 — 값이 그 타입의 객체로 **하나로 풀림 · 여럿에 맞음 · 못 찾음**을 일괄 입력의 이름 풀이로 센 것. 확실할 때만 참조로 제안한다(ADR 0009) | 매칭 후보 · 연결 추천 · 자동 매핑 |
| 통계 | 목록 화면에서 **그때그때** 세는 것 — 기준 하나(세부 기준 하나)로 묶고, 저장하지 않는다 | 집계 · 요약 |
| 지표 | 기록을 **미리 세어 두는 정의**(ADR 0013) — 원천 타입 · 집계 · 시간 · 기준 · 거르기 · 분모를 정하면 작업이 계산해 두고, 조회는 저장된 값을 읽는다. 디지털 트윈 역량의 「평가 축」은 지표가 아니다 | 메트릭 · 대시보드 · KPI · 큐브 |
| 기준 (지표의) | 지표가 묶는 칸 — 통계의 「기준」과 같은 말. 자기 속성이거나 이어진 것 너머의 칸(`ref.model.ref.base_model`) | 차원 · 디멘션 · 축 |
| 기간 단위 | 날짜를 묶는 크기 — 일 · 주 · 월 · 분기 · 해 | 그레인 · 버킷 · 해상도 |
| 기간 | 지표의 시간 칸(접수일 · 생산일 …)을 기간 단위로 묶은 한 칸 — 「2026-09」 | 피리어드 · 구간 |
| 코호트 | 기록을 두 번째 날짜(판매월 · 생산월)로 묶은 한 칸 — 「언제 팔린 것들」 | 집단 · 세대 |
| 경과 | 기간과 코호트의 차 — 「판매 후 3개월째」. 단위는 코호트의 기간 단위 | 나이 · 에이지 · 사용 개월(안내문에서는 허용) |
| 분모 | 비율을 낼 때 나누는 다른 지표(판매 대수 · 생산 대수) — 기준의 이름으로 짝을 맞춘다 | 모수 · 베이스 · 노출 |
| 계산 시각 | 지표 값을 마지막으로 센 때 — 그 뒤 들어온 기록은 아직 안 세어졌다 | 갱신 시각 · 스냅샷 시각 |
| 닫힌 기간 | 더 안 바뀌는 기간 — 계산 시각에서 「닫힘 일수」 만큼 지난 기간. 그 안의 기간은 늦게 들어오는 기록으로 바뀔 수 있다 | 확정 기간 · 마감 |
| 겹침 | 한 기록이 여러 칸에 드는 것(여러 값 칸 · 여럿에 이어진 것) — 합이 기록 수보다 크다. 통계와 지표가 같은 말을 쓴다 | 중복 집계 · 오버랩 |
| 건 보기 | 지표의 한 칸에서 **그 수를 이룬 기록의 목록**으로 가는 것 — 같은 조건으로 거른 목록 | 드릴다운 · 드릴 · 상세 보기 |
| 묶음 (사이드바 묶음) | 사이드바에서 타입을 묶는 단위 (`NavGroup`) | 그룹 · 카테고리 |
| 소속 타입 | 묶음에 속한 타입 | 걸린 타입 |
| 인터페이스 | 여러 타입이 따르는 공통 모양 — 공통 속성의 묶음. 객체를 갖지 않는다 (`ObjectInterface`) | 상위 타입 · 부모 타입 · 추상 타입 · 템플릿 |
| 구현 · 구현 타입 | 타입이 인터페이스를 따르는 것과 그 타입 — 한 타입이 여럿을 구현한다 | 상속 · 하위 타입 · 자식 타입 |
| 구현 추가 · 구현 해제 | 타입에 인터페이스를 더하고 빼는 것. 해제해도 속성은 남는다 | 상속하기 · 붙이기 · 떼기 |
| 공통 속성 | 인터페이스가 정한 속성 — 구현 타입마다 **같은 속성 키**로 있다 | 상속 속성 · 공유 필드 |
| 상위 인터페이스 | 인터페이스가 이어받는 인터페이스 (`extends_slugs`) | 확장(「확장」 은 확장 모듈이다) · 부모 |
| 인터페이스 목록 | 구현 타입 전부의 객체를 한 목록으로 보는 화면 | 통합 목록 · 전체 목록 |
| 부서 | 자료의 소유 단위 (`Workspace`) | 워크스페이스 · 팀 |
| 액세스 토큰 | 스크립트 · AI 도구용 자격 (PAT) | 개인 토큰 · API 키 |
| 일괄 입력 | 여러 건을 한 번에 입력하는 화면 — 표에 붙여넣거나 파일 업로드. 같은 식별자면 수정 | 파일 가져오기 · 일괄 등록 · 벌크 업로드 |
| 뷰 · 저장된 뷰 | 목록의 조건 · 열 구성 | 필터 세트 |
| 홈 게시 | 뷰를 부서 홈에 올리는 것 | 핀 · 위젯 올리기 |
| 확장 모듈 | 인스턴스마다 켜는 기능 모듈 (`app/extensions/<이름>`) | 플러그인 · 애드온 |
| 사용 중 · 미사용 | 확장이 켜졌나 (서버 › 확장 모듈) | 활성 · 비활성 · ON/OFF |
| 인스턴스 | 같은 번들로 띄운 한 설치 (`APP_SLUG`) | 플랫폼(제품군을 말할 때만) |
| 코어 · 코어 공개 | 타입을 외부 시스템에 공개하는 것(`core`) | 바깥에 열기 · 개방 |
| 공개 타입 | 코어로 공개한 타입 | 열려 있는 타입 · 열린 타입 |
| 수신 시스템 | 공개된 자료를 가져가는 외부 시스템 | 받아 가는 쪽 · 상대 |
| 조회 이력 | 외부 시스템이 코어를 조회한 기록 (`core.pull`) | 받아 간 것 · 가져간 기록 |
| 수신 기준 시각 | 어디까지 받았는지 나타내는 값 (`as_of`) | 시계 |
| 삭제 표식 | 삭제·병합된 항목을 알리는 행 (`deleted`) | 무덤 |
| 지운 객체 · 영구 삭제 | 삭제해도 기록으로 남은 객체(`deleted_at`)와, 그 행까지 없애는 것 — **타입 삭제에서만** 하고 되돌릴 수 없다(ADR 0008) | 휴지통 · 완전 삭제 · 하드 삭제 · 퍼지 |
| 연동 키트 | 수신 측에 전달하는 안내서 · 스크립트 묶음 | 클라이언트 꾸러미 |

## 디지털 트윈 역량 (확장 `caegroup`)

| 말 | 뜻 | 쓰지 않는 말 |
| --- | --- | --- |
| 연계 | 대상과 시뮬레이션의 조합 — 평가의 단위 | 짝 · 페어 |
| 시험 연계 | 시험을 시뮬레이션이 대신 확인하는 연계 — 축 다섯을 다 잰다 | 일반 연계 |
| 전용 검토 | 대응 시험이 없어 시뮬레이션만으로 판단하는 연계(시장 불량 판단 등) — 가상검증률 · 시험 대체를 재지 않는다 | 스팟 · 단독 해석 |
| 시뮬레이션 전용 검토 항목 | 전용 검토의 대상. 시험 항목 목록과 섞지 않는다 | 판단 항목 |
| 연계 등록 · 연계 해제 | 연계를 만들고 없애는 것 | 잇기 · 끊기 · 연결하기 |
| 기준 정보 설정 · 기준 정보 생성 | 시험 항목 · 시뮬레이션으로 쓸 온톨로지 타입 지정 | 초기 세팅 · 셋업 |
| 평가 축 (축) | 무엇을 보는 눈 — 가상검증률 · 자동화 · 모델링 수준 · 적용 범위 · 시험 대체 | 지표 항목 |
| 수준 | 축에서 지금 어디까지 왔는지 나타내는 단계 | 칸 · 등급 · 레벨 |
| 가상검증률 | 시험 결과와의 일치 수준(%) — 값이 수준을 정한다 | 정확도 · 일치율 |
| 근거 · 근거 등급 · 근거 자료 | 무엇을 보고 평가했나(진술 · 확인 · 검증)와 그 자료 | 증빙 · 소스 |
| 평가 완료율 | 평가된 연계 ÷ 전체 연계 | 커버리지 · 충족률 |
| 인력 · FTE | 담당 인원과 환산 인원 | 사람 줄 · 공수 |
| 인프라 | S/W 라이선스 · 계산 자원 · 물성 | 기반 · 자원 현황 |
| 일괄 입력 | 현재값을 표로 받아 고쳐 한 번에 저장하는 화면 | 벌크 업로드 · 대량 등록 |
| 전사 공유 | 여러 부서가 함께 쓰는 자원 — 전사 합계에서 한 번만 센다 | 공용 · 쉐어 |
| 고를 수 있는 값 (목록) | S/W 단위 · 용도처럼 설정에서 고치는 목록 — 저장되는 것은 키다 | 코드값 · 공통코드 · 마스터 |

**동사형으로 부르지 않는다.** 화면의 이름은 명사형이고(「연계 등록」), 단추만 동작을 짧게
적는다(「등록」 · 「해제」) — 「잇기」 처럼 말맛으로 지은 이름은 문서 · API · 화면에서 서로
다르게 번역되고, 그때 같은 기능을 세 가지 이름으로 부르게 된다.
