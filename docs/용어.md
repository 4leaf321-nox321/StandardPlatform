# 화면 용어 — 명사형 · 공식 표현

> 화면(메뉴 · 단추 · 열 이름 · 제목 · 안내문 · 오류 메시지)에 쓰는 말의 정본. 새 화면을 만들거나 문구를 고칠 때
> 여기 표를 따른다. 코드 주석은 해당 없다(주석은 설명이 우선).

## 규칙

1. **이름은 명사형.** 단추 · 메뉴 · 열 이름 · 대화상자 제목은 「~하기」 가 아니라 명사 — 「수정」 「삭제」 「재발송」 「홈 게시」.
2. **동작은 공식 동사.** 안내문에서 동작을 말할 때는 아래 표의 동사를 쓴다 — 「고치다 · 지우다 · 넣다 · 누르다 · 걸다」 같은 구어는 쓰지 않는다.
3. **부정은 「~하지 않습니다」.** 「안 삭제합니다」 가 아니라 「삭제하지 않습니다」.
4. **개념어는 하나로.** 같은 것을 두 이름으로 부르지 않는다(아래 「개념」).

## 개념

| 쓰는 말 | 뜻 | 다른 말로 부르지 않는다 |
| --- | --- | --- |
| 타입 | 객체의 종류 (`ObjectType`) | 종류 · 클래스 |
| 객체 | 타입의 인스턴스 | 항목 · 레코드 |
| 속성 · 속성 정의 | 타입이 담는 칸과 그 정의 | 필드 · 칸(안내문에서 「칸」 은 허용) |
| 식별자 | 타입 안에서 유일한 코드 (`key`) | 키 · 코드 |
| 이름 | 사람이 읽는 표시명 (`label`) | 라벨 |
| 관계 · 관계 종류 | 객체 사이의 연결과 그 정의 | 링크 · 엣지 |
| 참조 속성 | 칸에 저장한 관계 (`object_ref`) | 참조 칸 |
| 묶음 (사이드바 묶음) | 사이드바에서 타입을 묶는 단위 (`NavGroup`) | 그룹 · 카테고리 |
| 소속 타입 | 묶음에 속한 타입 | 걸린 타입 |
| 부서 | 자료의 소유 단위 (`Workspace`) | 워크스페이스 · 팀 |
| 액세스 토큰 | 스크립트 · AI 도구용 자격 (PAT) | 개인 토큰 · API 키 |
| 일괄 입력 | 여러 건을 한 번에 입력하는 화면 — 표에 붙여넣거나 파일 업로드. 같은 식별자면 수정 | 파일 가져오기 · 일괄 등록 · 벌크 업로드 |
| 뷰 · 저장된 뷰 | 목록의 조건 · 열 구성 | 필터 세트 |
| 홈 게시 | 뷰를 부서 홈에 올리는 것 | 핀 · 위젯 올리기 |
| 확장 모듈 | 인스턴스마다 켜는 기능 모듈 (`app/extensions/<이름>`) | 플러그인 · 애드온 |
| 사용 중 · 미사용 | 확장이 켜졌나 (서버 › 확장 모듈) | 활성 · 비활성 · ON/OFF |
| 인스턴스 | 같은 번들로 띄운 한 설치 (`APP_SLUG`) | 플랫폼(제품군을 말할 때만) |
| 코어 · 코어 공개 | 타입을 외부 시스템에 공개하는 것(`core`) | 바깥에 열기 · 개방 |
| 공개 타입 | 코어로 공개한 타입 | 열려 있는 타입 · 열린 타입 |
| 수신 시스템 | 공개된 자료를 가져가는 외부 시스템 | 받아 가는 쪽 · 상대 |
| 조회 이력 | 외부 시스템이 코어를 조회한 기록 (`core.pull`) | 받아 간 것 · 가져간 기록 |
| 수신 기준 시각 | 어디까지 받았는지 나타내는 값 (`as_of`) | 시계 |
| 삭제 표식 | 삭제·병합된 항목을 알리는 행 (`deleted`) | 무덤 |
| 연동 키트 | 수신 측에 전달하는 안내서 · 스크립트 묶음 | 클라이언트 꾸러미 |

## 디지털 트윈 역량 (확장 `caegroup`)

| 말 | 뜻 | 쓰지 않는 말 |
| --- | --- | --- |
| 연계 | 시험 항목과 시뮬레이션의 조합 — 평가의 단위 | 짝 · 페어 |
| 연계 등록 · 연계 해제 | 연계를 만들고 없애는 것 | 잇기 · 끊기 · 연결하기 |
| 기준 정보 설정 · 기준 정보 생성 | 시험 항목 · 시뮬레이션으로 쓸 온톨로지 타입 지정 | 초기 세팅 · 셋업 |
| 평가 축 (축) | 무엇을 보는 눈 — 가상검증률 · 자동화 · 모델링 수준 · 적용 범위 · 시험 대체 | 지표 항목 |
| 수준 | 축에서 지금 어디까지 왔는지 나타내는 단계 | 칸 · 등급 · 레벨 |
| 가상검증률 | 시험 결과와의 일치 수준(%) — 값이 수준을 정한다 | 정확도 · 일치율 |
| 근거 · 근거 등급 · 근거 자료 | 무엇을 보고 평가했나(진술 · 확인 · 검증)와 그 자료 | 증빙 · 소스 |
| 평가 완료율 | 평가된 연계 ÷ 전체 연계 | 커버리지 · 충족률 |
| 인력 · FTE | 담당 인원과 환산 인원 | 사람 줄 · 공수 |
| 인프라 | S/W 라이선스 · 계산 자원 · 물성 | 기반 · 자원 현황 |

**동사형으로 부르지 않는다.** 화면의 이름은 명사형이고(「연계 등록」), 단추만 동작을 짧게
적는다(「등록」 · 「해제」) — 「잇기」 처럼 말맛으로 지은 이름은 문서 · API · 화면에서 서로
다르게 번역되고, 그때 같은 기능을 세 가지 이름으로 부르게 된다.

동사형이 그대로 나갔다. 새 기능을 만들 때 이 표를 먼저 보지 않으면 그 화면만 말투가 달라진다 —
위에 디지털 트윈 역량 절을 두어 다음 단계(평가 · 대시보드 · 인력 · 인프라)가 같은 말을 쓰게 했다.

2026-09-24 — 코어(외부 공개) 관련 화면과 그 뒤에 추가된 화면(작업 · 일괄 입력 · 데이터 소스 ·
웹훅)의 문구를 다시 맞췄다. **새 기능을 만들 때 이 표를 건너뛰면 그 화면만 말투가 달라진다** —
실측으로 그렇게 됐다(코어 화면의 「열려 있는 타입」 · 「읽을 수 있는 자격」 · 「받아 간 것」).
