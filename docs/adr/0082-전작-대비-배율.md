# 0082. 전작 대비 배율 — 판매 대수당 건수가 전작의 몇 배인가, 점추정과 95% 구간

## 배경

순차 검정은 「ρ 배 나쁜가 · 아닌가」 를 매 기간 묻는 **판정**이다. 보고에서 먼저 묻는 것은 **수**다 — 「새 모델의 인입률이
전작의 몇 배인가, 얼마나 확실한가」, 그리고 그것을 시장마다 늘어놓은 전수표(시장 165곳). 순차 검정의 값마다 훑기는 40개에서
자르고 값마다 질의를 두 번씩 돈다.

## 결정

1. **배율은 경과를 맞춘다** — 새 모델은 갓 팔린 것이 많아 달력 시점의 「건수 / 판매 대수」 를 그대로 견주면 좋아 보인다.
   순차 검정과 같은 간접 표준화: 전작의 경과별 비율 r_a 로 새 모델 코호트마다 N_c · r_a 를 더한 기대 E, **배율 = O / E**.
   경과를 안 맞춘 **단순 배율**(대수당 건수의 비)도 함께 낸다 — 둘이 크게 다르면 경과 구성 차이다.
2. **95% 구간은 두 모델의 흔들림을 함께** — ln 척도에서 `1.96 · √(φ · (1/O + V_E/E²))`. V_E 는 전작 비율의 포아송
   분산을 기대 건수로 옮긴 것(델타법 — 전작이 작으면 넓어진다), φ 는 전작의 코호트마다 잰 과분산(순차 검정과 같다, 1 이상).
   O = 0 이면 위 끝만(정확 포아송 3.69 / E 에 같은 넓힘), E = 0 이면 배율이 없다(`new`). 시험에서 참 배율 1.5 를 포아송으로
   400번 뽑아 구간이 덮는 몫이 92 ~ 98% 안이다.
3. **판정 말** — `higher`(구간이 1 위) · `lower`(1 아래) · `unclear`(1 을 품는다 — 「같다」 가 아니다).
4. **`by` 는 값 전부** — 상한이 없다. 두 모델의 틀을 `by` 로 묶어 **한 번씩** 읽고 값마다 나눈다(셀 상한 20만 안 —
   넘으면 다른 분석처럼 거절). 분모가 그 기준과 짝이면(시장) 그 값의 판매 대수, 아니면(증상) 모델의 판매 대수를 모든
   값이 함께 쓴다(`shared_exposure`). 과분산은 전체에서 잰 것을 값마다 쓴다(값 하나의 전작 코호트는 대개 너무 적다).
   값마다 따로 본 구간이라 다중 비교 보정은 없다 — 주의(`per_value_intervals`)로 말한다. 차례는 「높다」 · 전작에 없던
   값이 먼저, 배율이 큰 것부터.

## 대안

- **표준화 비의 정확 구간(가우드)** — 버렸다. E 를 고정된 값으로 봐 전작이 작을 때 구간이 너무 좁다.
- **단순 배율만** — 버렸다. 출시 초기의 새 모델이 늘 좋아 보인다.
- **값마다 보정(본페로니)** — 버렸다(이번에는). 전수표는 하나하나의 구간을 보는 표다. 「어느 값이 나빠졌나」 의 판정은 순차
  검정 훑기(α/K)가 맡는다.

## 결과

- 「전작 대비 몇 배 · 구간 · 시장마다」 가 도구 한 번이다. 경보(알림)는 순차 검정에만 건다 — 배율은 수를 보는 분석이다.
