# 0029. MCP 운영 도구 — 화면의 관리 기능을 AI 도, 관리의 쓰기는 열지 않고

- 상태: 채택(2026-10-15 구현 — 새 도구 열여섯 · 넓힌 도구 넷, 도구 일흔여섯 → 아흔둘, 위험 도구 열일곱 → 스물)
- 날짜: 2026-10-15
- 관련: [ADR 0028](0028-HWAX-포털에-붙이기.md)(게이트웨이 위임 · 위험 도구), [ADR 0016](0016-경보.md)(경보),
  [ADR 0027](0027-검토함.md)(검토함), `shared/scopes.py`(「모르는 것은 막는다」), `auth/delegation.py`

## 배경

화면에는 있는데 MCP 에는 없는 기능을 사용자가 물었다(API 302 개 중 MCP 가 부르지 않는 것 190 개 — 같은 일을 다른
길로 하는 것을 빼면 기능 단위로 열댓 갈래). 사용자는 「보안 · 사람 전용을 빼고 웬만한 것은 다」 를 요청했다.

두 원칙과 부딪친다.

- **도구 목록이 길어질수록 모델은 엉뚱한 것을 고른다**(`server.py` 머리). 기능마다 도구를 내면 목록이 두 배다.
- **토큰의 쓰기는 범위 표에 연 경로만**(`shared/scopes.py`), 그리고 **계정 · 부서 · 서버 관리는 어느 범위로도
  안 열린다**(`auth/delegation.py` — 게이트웨이 너머의 AI 에게 저절로 가지 않게).

## 결정

1. **도메인마다 「읽기 하나 · 고치기 하나」, 지우기는 하나로.** `config_delete(kind=metric · metric_alert ·
   datasource · view)` 는 `ontology_delete(kind=…)` 와 같은 모양이다. 읽기는 「목록 / 하나」 를 한 도구로
   (`workspaces(slug=)`, `webhooks(webhook_id=)`, `datasources_list(slug=, suggest=, boards=)`), 이미 있는 도구는
   인자를 넓힌다(`metric_alerts(alert_id=, check=)`, `job_apply(job_ids=)`, `job_cancel(job_ids=)`).
2. **고치는 것은 미리 보기가 기본**(`apply=False`). 경보 걸기의 미리 보기는 그 인자로 **지금 분석을 한 번 돌려**
   보인다 — 저장하면 지금 있는 결론은 알리지 않으므로, 무엇이 「처음부터 있던 것」 이 되는지 사람이 본다.
3. **이미 토큰에 열린 경로만 쓴다 — 범위 표를 MCP 때문에 넓히지 않는다.** 부서 · 공지 · 웹훅 · 서버는 **읽기만**
   (`workspaces` · `notices` · `webhooks` · `server_status`). 처음에는 부서 구조 · 공지 · 웹훅 다시 보내기 · 확장
   켜기 도구도 만들었으나, 진짜 앱에 붙이자 `403 APP-AUTH-0105 「개인 토큰으로는 이 경로를 고칠 수 없습니다」`
   였고, 그 자리는 위의 원칙이 일부러 닫은 것이었다(확장 켜기는 `main.py` 에 「토큰에 열지 않는다」 고 적혀 있다).
   범위를 여는 대신 도구를 걷어냈다. 열려면 이 ADR 을 고쳐 따로 정한다 — 그때도 `…:admin` 으로 지어 게이트웨이
   위임에서 빠지게 한다.
4. **보안 · 사람 전용은 넣지 않는다.** 로그인 · 토큰 · 계정, 부서 구성원 · 역할, 웹훅 등록 · 수정 · 삭제(바깥
   주소 · 서명 비밀), 온톨로지 초기화, 접근 기록(사람의 열람 기록), 데이터 소스의 **인증 비밀**(`datasource_save`
   가 `auth_secret` 을 거절한다 — 비밀이 대화와 기록에 남는다, 사람이 화면에서 넣는다), 알림 읽음(사람이 본
   것으로 둔다 — 원래의 결정 그대로).
5. **파일 바이트는 모델을 거치지 않는다**(ADR 0012 와 같은 이유). 내보내기는 `export_start` 가 **작업만** 시작하고
   파일은 사람이 화면의 「작업」 에서 받는다. 사진 묶음 올리기 · 통계 · 정의 · RDF · 키트의 파일 내려받기는 MCP 에
   없다 — 내용은 이미 있는 읽기 도구(`objects_summary` · `ontology_schema` · `rdf_query`)로 읽는다.
6. **위험 도구 목록**(게이트웨이 범용 실행기 차단)에 `config_delete` · `review_undo` · `jobs_purge` 를 더한다 —
   되살릴 수 없는 지우기와 되돌리기다. 요청서 틀(`docs/[참고] HWAX포탈_연동_요청서.md`)도 같이(시험이 견준다).

## 넣은 것

| 도구 | 무엇 | 백엔드 경로(범위) |
| --- | --- | --- |
| `metric_alert_save` · `metric_alerts`(넓힘) | 경보 걸기 · 이름 · 끄기, 경보 하나의 발생 · 지금 확인 | `/api/metrics/…/alerts`(`ontology:write`) |
| `config_delete` | 지표 · 경보 · 데이터 소스 · 뷰 지우기 | 각 자리(`ontology:write` · `objects:write`) |
| `datasource_save` · `datasources_list`(넓힘) | 소스 만들기 · 고치기 · RA 보고서 기록 타입, 소스 하나 · 대응 초안 · RA 게시판 | `/api/datasources`(`objects:write`) |
| `core_status` | 외부 공개 현황 — 안 나가는 관계 종류 · 참조 속성까지 | 읽기 |
| `views` · `view_save` | 저장된 뷰 | `/api/objects/…/views`(`objects:write`) |
| `object_watch` · `object_years` | 지켜보기 · 연도 배정 | `/api/objects/…`(`objects:write`) |
| `workspaces` · `notices` · `webhooks` · `server_status` | 부서 · 공지 · 웹훅 · 서버 — **읽기만** | 읽기 |
| `review_history` · `review_undo` | 검토함의 지난 결정 · 정확도 · 묶음 되돌리기 | `/api/review`(`objects:write`) |
| `jobs_purge` · `job_apply`/`job_cancel`(넓힘) | 작업 정리 · 여럿 한 번에 | `/api/jobs`(`objects:write`) |
| `export_start` | 객체 · 관계 내보내기 작업 | 읽기로 연 POST |

## 결과

- 가짜 백엔드 시험(`mcp_server/tests`): 미리 보기가 기본 · 종류마다 제 자리 · 비밀 거절 · 관리 설정은 지우기 거절 ·
  내보내기의 거르기 · 작업 여럿 · 코어 현황의 칸 줄이기 · 느린 곳의 경로.
- 진짜 앱 시험(`tests/api/test_mcp_admin_tools.py`): 코어 현황 · 서버 상태, 부서 · 공지 · 웹훅은 읽기만(관리 쓰기
  도구가 없고 부서 지우기는 거절), 뷰 저장 · 고치기 · 지우기 · 지켜보기 · 연도 배정, 데이터 소스 만들기 · 고치기 ·
  지우기(비밀 거절), 경보 걸기(미리 보기에 지금 분석) · 지금 확인 · 끄기 · 지우기, 검토 이력 · 내보내기 작업 ·
  작업 정리 미리 보기 — 모두 PAT 로 진짜 라우터를 탄다.
- 안내서 `GUIDE_VERSION 2026-10-15a` — 주제 `admin`(운영 · 설정)과 「MCP 로 하지 않는 것」.
