# 0064. 저장소는 공개로 둔다 — 사내 주소 · IP · 계정은 .env 와 저장소 밖으로, 라이선스는 무단 사용 금지

- 상태: 채택(2026-11-08)
  - 코드: `config.url_origin` — `PORTAL_ISSUER` 를 안 적으면 `PORTAL_LAUNCH_URL`(없으면 `PUBLIC_URL`)의 앞부분,
    못 정하면 포털 로그인을 거절하고 서버 화면 · `env-check.sh` 가 말한다. `deploy.sh setup` 의 호스트명은 기본값 없이
    묻는다
  - 문서 · 예시 설정: 사내 호스트 → `<포털 호스트>`, 서버 IP → `<A>` · `<B>` · `<메인 서버 IP>`(예는 192.0.2.x),
    계정 → `<계정>`. 실제 값은 `docs/사내/사내-주소.md`(커밋하지 않는다)
  - `scripts/before_push.sh` 의 「사내 호스트 · IP · 계정이 추적 파일에 없다」 — 목록은 `docs/사내/금지-문자열.txt`
  - `LICENSE`(무단 사용 금지) · `THIRD_PARTY_NOTICES.md`, 화면 빌드의 `dist/THIRD_PARTY_NOTICES.txt`, 번들의
    `os-packages.txt` · LICENSE · 고지(키트에도)
- 날짜: 2026-11-08
- 관련: [ADR 0028](0028-HWAX-포털에-붙이기.md)(포털 로그인 · 위임)

## 배경

저장소는 GitHub 공개다 — 무료로 main 을 보호하고, 서버가 인증 없이 릴리스를 받기 때문이다. 그런데 사내 포털 호스트가
추적 파일 12개(설정의 기본값 포함)에, 실제 서버 IP 와 계정 이름이 설치 안내에 들어 있었고, 라이선스 파일이 없었다.
NVIDIA Auto Ontology 와 견준 조사(2026-11-07, SP 개선 목록 「먼저」 6번)에서 나왔다 — AO 는 공개 카탈로그로 나가는 묶음에
「사내 호스트명 · 자격 증명 금지」 를 규칙으로 둔다.

## 결정

1. **공개를 유지한다**(사용자가 정함, 2026-11-07).
2. **사내 호스트는 `.env` 로** — 코드에 기본값을 두지 않는다(사용자가 정함, 2026-11-08). 포털의 기본 `iss` 는 포털 자기
   주소라, 포털을 붙인 설치가 이미 적는 `PORTAL_LAUNCH_URL` 의 앞부분과 같다 — 기존 설치는 그대로 돈다. 셋 다 없는
   설치만 갱신 뒤 포털 로그인이 막히는데, 서버 화면 · `env-check.sh` 가 오류로 말한다.
3. **IP · 계정은 자리 표시로** — 실제 값은 저장소 밖(`docs/사내/`). 이미 이력에 남은 값은 지워지지 않는다(이력까지
   가리는 길은 비공개 전환뿐이다).
4. **라이선스는 무단 사용 금지**(사용자가 정함, 2026-11-08) — 저작권자는 중립 표기(「Standard Platform 저작권자」).
   공개되어 있어도 GitHub 이용약관의 보기 · 포크 말고는 허락하지 않는다.
5. **제3자 라이선스 점검**(2026-11-08) — 막는 것은 없다. 앱이 쓰는 라이브러리에 GPL · AGPL · SSPL · 비상업 · 라이선스
   없음이 없고, 조건부는 psycopg(LGPL-3.0 — 고치지 않고 import) · certifi(MPL-2.0) · numpy/scipy 휠의 GCC 런타임(예외
   조항)뿐이다. 다만 **릴리스가 공개 GitHub Release 로 나가므로** 고지를 채운다: 압축한 화면 번들에 라이선스 주석이
   하나도 남지 않아(145개 JS 중 0개) 빌드가 실제로 든 패키지의 고지를 모으고, 이미지의 GPL · LGPL OS 패키지는 목록과
   소스 위치를 번들에 넣는다.

## 대안 — 버린 것

- **비공개로 전환.** 이력까지 가린다. 그러나 비공개 브랜치 보호에 요금제가 들고, 서버의 릴리스 받기에 읽기 토큰이
  필요하다.
- **포털 호스트를 코드의 기본값으로 두되 문서에서만 가리기.** 공개 저장소의 코드가 그대로 드러낸다.
- **CI 에도 금지 문자열 검사.** 목록이 사내 정보라 CI 비밀로 넣어야 한다 — 우선 푸시 전 점검(로컬, 목록은 저장소
  밖)만. 필요하면 CI 비밀로 옮긴다.
