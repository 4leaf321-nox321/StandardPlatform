# 0030. 위험 도구는 시스템 관리자만 — MCP 가 서버의 권한보다 좁힌다

- 상태: 채택(2026-10-15 구현)
- 날짜: 2026-10-15
- 관련: [ADR 0028](0028-HWAX-포털에-붙이기.md)(게이트웨이 · 위험 도구 목록), [ADR 0029](0029-MCP-운영-도구.md)(운영 도구),
  `mcp_server/server.py` 의 `DESTRUCTIVE_TOOLS` · `_admin_only`

## 배경

`DESTRUCTIVE_TOOLS`(20개 — 지우기 · 합치기 · 되돌리기 · 덮어쓰기 · 멈추기 · 계획 적용)는 원래 HWAX 게이트웨이의 범용
실행기(`invoke_tool`)에서 막아 달라고 요청하는 목록이었다(ADR 0028). 그것은 **AI 가 도구를 스스로 골라 부를 때**만
막고, 사람이 고른 도구(직접 바인딩)나 Claude Code 처럼 게이트웨이를 거치지 않는 연결은 그대로 둔다. 그 뒤의 권한은
서버의 권한 = 화면의 권한이라, **부서 관리자의 토큰이면 AI 가 그 부서 객체를 지우고 합치고 계획을 적용한다.**

사용자는 「위험한 도구는 시스템 관리자만 할 수 있게」 를 요청했다(2026-10-15).

## 결정

1. **MCP 서버가 위험 도구를 시스템 관리자만 쓰게 한다.** 도구를 부를 때마다 `GET /api/auth/me` 로 토큰 주인이 시스템
   관리자인지 묻고, 아니면 **백엔드에 아무것도 보내지 않고** `{"error": …, "admin_only": true}` 를 돌려준다. 오류 문구는
   「화면에서 하거나 시스템 관리자에게 요청하라 — 다른 도구로 우회하지 않는다」 를 모델에게 시킨다.
2. **미리 보기도 막는다.** 미리 보기는 해가 없지만, 미리 보기를 보여 주고 「적용할까요」 를 묻는 대화가 시작되면 사람은
   적용이 될 줄 안다 — 끝에서 막히는 것보다 처음에 막히는 것이 덜 헛걸음이다.
3. **좁히기만 한다.** 서버의 권한은 그대로다 — 같은 부서 관리자가 화면에서는 자기 부서 객체를 지운다. 「MCP 로는 되는데
   화면에서는 안 되는」 상태는 여전히 안 생긴다(`server.py` 의 「권한은 서버가 본다」 에서 벗어나는 것은 그 방향뿐이다).
4. **목록 하나가 두 일을 한다.** 게이트웨이 차단 목록 = 관리자 전용 목록. 도구 등록(`tool()`)이 그 이름을 보고 확인을
   건다 — 새 위험 도구를 목록에 넣는 것만으로 걸린다(도구마다 따로 걸면 하나를 잊는다). 확인은 매번 묻는다 — 토큰
   주인이 관리자에서 빠지면 바로 막힌다(캐시하지 않는다, 한 번에 수십 ms).
5. **`extension_call` 은 읽기(GET)는 그대로.** 확장의 읽기에도 쓰이는 도구라 `method` 가 GET 이 아닐 때만 막는다.
6. **관리자인지 못 물으면 열지 않는다.** `/api/auth/me` 의 오류를 그대로 돌려준다(401 은 다른 도구처럼 올려 게이트웨이가
   토큰을 다시 받게 한다).

## 결과

- 시스템 관리자가 아닌 사람은 MCP 로 **대량 넣기의 적용(`job_apply`) · 검토함 결정(`review_decide`) · 일괄 고치기
  (`bulk_edit`) · 관계 끊기(`relation_remove`)** 도 못 한다 — 계획 · 미리 보기는 세우되(`objects_import` 는 위험 도구가
  아니다) 적용은 화면의 「작업」 에서 사람이 한다. 이것이 너무 좁으면 그 도구를 목록에서 빼는 것이 아니라(게이트웨이
  차단도 같이 빠진다) 이 ADR 을 고쳐 관리자 전용 목록을 따로 둔다.
- 시험: 가짜 백엔드(`mcp_server/tests` — 막을 때 백엔드에 아무것도 안 감 · 미리 보기도 · 확장 읽기는 열림 · 관리자인지
  못 물으면 그 오류), 진짜 앱(`tests/api/test_mcp_tools.py` — 부서 관리자 토큰은 자기 부서 객체도 MCP 로는 못 지우고
  화면(세션)에서는 지운다, 고치기는 화면과 같다).
- 안내서 `GUIDE_VERSION 2026-10-15b` — 첫 규칙에 「위험 도구는 시스템 관리자만」 과 목록.
