# 0063. 말의 자리 — 시스템마다 다른 코드 · 이름을 어디에 두나

- 상태: 채택(2026-11-08 — 글과 결정. 코드는 두 번째 자리가 실제로 생길 때)
  - GUIDE 모델링 §4 「말의 자리」 표, `pipeline/AGENTS.md` 의 같은 줄
  - datarelay 개발계획 ⑥ 의 뒷부분(대응을 어디에)을 이 결정으로 닫는다 — 그쪽 세션에 전했다
- 날짜: 2026-11-08
- 관련: [ADR 0025](0025-채울-곳과-별칭-후보.md)(별칭 후보), [ADR 0062](0062-없음과-0건에-단서를-붙인다.md)(이름 짐작
  후보), datarelay ADR 0001(허브 앞단의 중계 플랫폼 — 「GLM 판정은 미확인 별칭으로」)

## 배경

같은 것을 시스템마다 다르게 부른다 — PLM 의 「SM-S931」 과 MES 의 「S25 기본」, QINGS 의 공급사 코드와 SP 의 공급사
이름. 이 짝을 둘 수 있는 자리가 여럿이다: SP 의 객체 별칭(`object_aliases`, 원천 코드는 `source:<slug>`), 속성의
`help`, 묶음의 `notes`, 정제 키트의 대응 파일(`map` · `dictionaries`), 그룹 사전, datarelay 레시피의 사전. 자리가
여럿이면 같은 짝이 두 곳에 다르게 적히고, 어느 쪽이 맞는지 아무도 모른다.

NVIDIA Auto Ontology 와 견준 조사(2026-11-07, SP 개선 목록 「먼저」 5번)에서 나왔다. AO 는 사전이 두 벌(사람이 쓰는
약어 · LLM 이 뽑는 동의어)로 갈려 서로를 모르고, LLM 이 뽑은 동의어는 사람이 고칠 길이 없다. 그리고 datarelay
개발계획 ⑥(「MES · PLM 코드가 대표 플랫폼 key 와 같은가, 다르면 대응을 어디에」)이 이 결정을 기다렸다.

## 결정

**정본은 SP 의 별칭이다** — 사용자가 정함(2026-11-08). 판단 표:

| 가리키는 것 | 둘 자리 | 누가 굳히나 |
| --- | --- | --- |
| 객체 하나(모델 · 부품 · 공급사의 다른 이름 · 약칭 · 원천 코드) | 그 객체의 **별칭** — 원천 코드는 `source:<slug>` 종류 | 사람(별칭 후보 · 검수). 기계가 붙인 것은 검수 대기 |
| 정의 하나(타입 · 칸 · 지표를 부르는 다른 말) | 그 정의의 설명 첫 줄(다른 이름) | 정의 편집자 |
| 고를 값의 원천 코드(`P` → 진행) | 그 속성의 `help`(대응) — 변환은 키트 대응 파일의 `map` | 정의 편집자 |
| 답하는 방식의 약속(「불량률은 대수 기준」) | 묶음 · 지표의 `notes` | 정의 편집자 |
| 여럿을 가리키거나 아무것도 안 가리키는 말 | 정하지 않는다 — 사람에게 묻고 모은다(설치 사전은 조건부) | — |

- **datarelay** — relay 는 SP 코어 API 의 별칭으로 받고(`aliases`), 자기 판정(규칙 · GLM)은 **미확인 별칭 제안**으로만
  SP 에 올린다. relay 사전은 SP 에 별칭이 굳기 전까지의 **임시 지름길**이다 — 굳으면 그 줄을 걷고, 둘이 다르면 SP 가
  이긴다. relay 사전을 정본으로 두지 않는다. (11-07 에 relay 쪽이 정한 「둘 다 — relay 사전으로 바로 풀고 같은 목록을
  별칭 등록 요청」 을 이 순서로 맞춘다.)
- **정제 키트** — 대응 파일의 `dictionaries` · `map` 은 그 변환의 입력일 뿐이다. 객체를 가리키는 짝은 넣을 때 별칭으로
  함께 싣는다(다음부터 이름 풀이 · 검색 · 코어 API 가 모두 그 말을 찾는다).

## 대안 — 버린 것

- **relay 사전을 정본으로.** relay 를 거치지 않는 길(화면 검색 · MCP 이름 풀이 · 다른 설치의 코어 API)은 그 짝을
  모른다. 사람이 고치는 화면 · 검수 · 감사도 SP 에만 있다.
- **설치마다 하나의 「사전」 표를 새로.** 별칭이 이미 객체마다 · 원천마다 · 검수까지 있다. 새 표는 두 번째 정본이 된다.
- **LLM 이 뽑은 동의어를 확인 없이 붙이기(AO 식).** 틀린 짝이 정본처럼 쓰인다 — 짐작은 후보로만(ADR 0062).
