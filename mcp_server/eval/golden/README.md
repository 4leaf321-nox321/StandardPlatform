# 한국어 정답 셋 — `sp-golden-1`(초안, 2026-11-08)

`cases.md` 는 「무엇을 시키나」 를 글로 적은 시나리오다. 이 셋은 거기에 **정답 호출**을 붙인다 — 질문마다 「이 질문의
정답은 이 도구를 이 인자로 부른 결과다」. 정답 **값은 적지 않는다**: 채점할 때 같은 계정 · 같은 때에 정답 호출을 돌려
그 결과와 AI 의 답을 견준다(자료가 늘면 값이 바뀌므로). SP 개선 목록 「먼저」 7번.

## 한 줄의 모양(`sp-golden-1.jsonl`)

| 칸 | 뜻 |
| --- | --- |
| `id` · `q` · `kind` | 문항 번호 · 사람이 묻는 말(그대로 AI 에게 시킨다) · 갈래 |
| `gold` | 정답 호출 — `tool`(MCP 도구 이름) · `args`. `{"$ref": "<타입>:<이름>"}` 은 채점 때 이름 풀이로 id 를 넣는 자리(id 는 설치마다 다르다) |
| `check` | 견주는 법 — `how`(무엇을 볼지) · `expect`(그 결과에서 나와야 하는 것, 있으면) |
| `must_call` · `must_not` | AI 가 꼭 불러야 하는 도구 · 하면 안 되는 것(자취와 답 글로 본다) |
| `truth` | 정답의 근거 — 개발 DB 에 심어 둔 신호면 그것 |
